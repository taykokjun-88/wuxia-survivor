# 计划书 20（给 Gemini）：为上 Steam 做的「版权清理 + 原创改名」

> 背景：游戏现在是朋友间免费试玩。要收费发布（Steam），其中**借用了金庸等武侠作品的名字、招式、人物、地名**，以及几段**禁止商用 / 授权不清的音频**必须清理。
> 这份计划书只做两件事：**① 给下面列出的每一项想一个原创新名字；② 帮我找可商用的替代音频**。我拿到结果后用脚本统一替换到游戏里（存档用的是内部 id，改名不会影响老存档和排行榜）。
> 我不是律师，下面的「风险」只是我的判断；改名的目标是**不和任何已出版的武侠作品撞名**，不是只换个谐音。

---

## 一、改名总规则（务必遵守）
1. **原创**：新名字不得与金庸、古龙、梁羽生、温瑞安、黄易等任何已出版武侠小说 / 游戏 / 影视里的人物名、招式名、功法名、地名、兵器名相同；**也不要只是换个同音字或近音字**（例如「灭绝师泰」「黄荣」这种谐音一律不算）。
2. **逐个查重**：每个新名字请**在网上搜索一次**，确认没有已知的武侠作品在用（搜 `新名字 武侠` 或 `新名字 招式`）。搜到有撞的就换。
3. **长度**：字数**不超过原名 +1 字**（界面是固定宽度）；招式名 2~5 字，功法名 3~5 字，人名 3 字（姓 + 两字名），地名 2~5 字。
4. **气质不变**：保持武侠古风、读着顺口、一看就知道大概是什么路数（拳 / 剑 / 刀 / 掌 / 内功 / 轻功），**属性相近的东西名字风格也要成套**（比如同一个心法体系的几个名字用同一类意象）。
5. **不能有**：真实历史人物、现实宗教的教主 / 神明名、现实品牌、其它游戏的专有名词。「杨家将」「少林」「华山」「峨眉」「昆仑」「崆峒」这类**真实存在的地名 / 山名 / 寺名 / 民间传说**可以保留，但**不要和金庸里某个具体人物绑定**。
6. **每个给 1 个主选 + 1 个备选**，并用**一句话**写这个名字的意象（我用来写描述）。
7. 同类的新名字**不能重复**，也**不能互相同音**。

## 五、交付格式
一个 Markdown 表格或 CSV（我直接粘贴用），**每一行**：

`类别 | 内部 id | 现名 | 新名（主选）| 新名（备选）| 一句话意象 | 查重结论（搜过了什么、有无撞名）`

- 第二节所有「必改 / 建议改」的行都要有新名；标注「可保留」的行请回答**「是 / 否保留」**，不保留的给新名。
- 人名一类给**姓 + 名**即可；Boss 的称号（如「黑风寨主·」「某某大师」）请一起给出新称号。
- 地名 / 门派 / 设定词（第 J、L 节）除了新名，还请给**一句话的原创设定**（谁在围攻谁、为什么），方便我改剧情文字。
- 音频（第三节）一行一项：`位置 | 替代音频名 | 作者 | 许可证 | 链接 | 署名写法 | 时长`。
