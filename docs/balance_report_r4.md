1. **开启售卖装备系统**：[scripts/hud.gd](../scripts/hud.gd) 升级为「售卖模式」（每件标 `+XX 银`、头部实时汇总入账、新增「一键售卖白/蓝装」），[data/game_data.json](../data/game_data.json) 与 [backend/Code.gs](../backend/Code.gs)（`v0.9-fix-2`）同步调高售卖银两至 `[30, 100, 350, 1000]`。
2. **A3 白板基础生存回补**：`player` 初始 `max_hp: 100 → 125`、`armor: 0 → 1.5`、`neili_regen: 8.4 → 10.0`、`hp_regen: 0.2 → 0.4`。
3. **四职业数值与天赋收口**：
   - 刀客回调 `blade_break_mult: 2.5 → 1.35`、`blade_soul_dmg: 0.025 → 0.015`、`blade_break_heal: 0.12 → 0.06` 及高伤招式基础值；
   - 剑客九变觉醒保持大后期定位：前期微调（`dugu: 40 → 44`），觉醒后封顶 `t_fenfeng`（5 层）并回调 `dugu_true_mult: 0.9 → 0.24`、`dugu_true_cd: 0.5 → 0.95`、`po_jian` 余波 `0.6 → 0.35`；同时补强常规剑法与剑客灵系非九变链；
   - 武者修复 `t_poju` 破境余波二次乘算、回调 `fist_ult_dur: 10 → 7s` / `fist_ult_true: 0.3 → 0.2` / `fg_g_8` 寸劲无双（`90` 劲 + `+15%` 范围），补强前期三起手伤害；
   - 杨家将补强刚/柔系棍法与无名枪法单体 Boss 输出，回调 `pg_g_8` 范围；
   - 保持海棠屿修为上限 Lv32 不变（Lv33~50 与极意留给 V1.1 新关卡）。
