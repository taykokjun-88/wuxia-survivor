# 美术需求：天赋树「三个框」背景图（给 Gemini，共 9 张）

## 用在哪
天赋树改成三个并排的框（**刚 / 柔 / 灵**），像 RO 技能树。每个框的背景要符合**当前流派**的角色，并对应这一系的气质——所以一共 3 流派 × 3 系 = **9 张**。目前游戏用各流派立绘压暗后占位，图到位后自动替换。

## 通用要求
- 尺寸：**404 × 490 像素**（竖版，约 0.82 : 1），jpg，≤ 200KB 一张。多画一点（如 808 × 980）也行，我来缩。
- 风格：和现有立绘 / 封面一致的**水墨武侠插画**，人物为**角色的一个姿态**（全身或大半身），背景有水墨山水。
- **关键：压低对比度与亮度。** 框内要叠 14 个穴位图标和文字，所以画面整体要**偏暗、偏灰、细节收敛**，人物放在**中间偏上**，不要有大面积纯白或高饱和色块；四周留白 / 烟雾。
- 三张同流派的图要像「同一个人的三个姿态」，色调统一，但每系有自己的主色：**刚 = 朱红 / 橙，柔 = 青 / 青绿，灵 = 紫 / 淡蓝**（只是点缀光效，不要整张染色）。
- 不要文字、不要边框、不要 UI。

## 画什么
| 流派 | 刚（催动 / 爆发 / 破防） | 柔（调息 / 回复 / 护体） | 灵（身法 / 冷却 / 福运） |
|---|---|---|---|
| 武者（拳掌）`fist` | 马步沉肩，一记崩拳轰出，拳风炸开，朱红气浪 | 盘膝入定 / 太极云手，周身青色真气环绕，衣袖飘然 | 凌空腾挪，足尖点云，身后留下紫色残影 |
| 剑侠（剑）`sword` | 双手握剑下劈，剑身带朱红剑气，衣袍猎猎 | 单手持剑静立、剑尖点地，青色微光与落叶环绕 | 一剑刺出的瞬间闪现，身后多重紫色剑影 |
| 刀客（刀）`blade` | 扛刀前冲、大刀劈下，赤金披风，刀身冒火星 | 收刀盘坐 / 单膝跪地调息，斗笠压低，青白气息缭绕 | 提刀疾奔，披风飞扬，脚下卷起紫蓝风尘 |
