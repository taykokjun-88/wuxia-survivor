## 0. 人设（所有图必须是同一个人）
前杨家军唯一的生还者，中年，沉稳。外形要点：
- **脸**：棱角分明，眉间 / 脸颊一道旧疤，目光沉静，不带笑。
- **发**：黑发用粗布头巾束起，鬓角有几缕白发。
- **衣着**：灰蓝色粗布外袍（打了补丁）；左肩 / 双护臂是**残破的银白色军甲**（杨家军的白银甲，有磕碰裂痕）；腰间束带，系着一块**磨旧的军牌**（不要写字）。
- **武器**：右手一杆**长枪**（枪身深木色，枪头银亮，**红缨**）；背后斜背一根**白蜡长棍**（浅色木，两端铁箍）。同一个人物在枪路时拿枪、棍路时握棍（精灵里统一画「手持长枪、背后背棍」；棍的动作在棍招式的帧里换成手持棍）。
- **配色**：灰蓝 + 银白 + 红缨点缀；比刀客（黑 / 赤金）、剑侠（白 / 青绿）、武者（青绿 / 红）更偏冷灰。
- **气质**：沉稳、坚毅，不张扬。
