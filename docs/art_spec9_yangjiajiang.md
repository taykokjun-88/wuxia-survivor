# 第二部分（B）：四个职业的创建角色高清立绘重做（贴合身世）
### B0. 用在哪与通用要求
创建角色界面左侧的大立绘（显示 390×520，所以出图 **896×1200，竖版 3:4，jpg**）。现在的四张只是「好看的人物站姿」，和刚写好的**身世**没有关系。要重画成**一张图讲一段故事**：人物 + 能一眼看出身世的细节 + 背景场景。

文件（覆盖同名，不要加版本后缀）：`assets/portraits/fist_hero.jpg`、`sword_hero.jpg`、`blade_hero.jpg`、`spear_hero.jpg`（杨家将是新的）。

#### 通用要求
- 高清**水墨武侠插画**风，精致手绘质感，线条干净、光影立体；四张**风格统一**、光源和色调体系一致（每个人有自己的主色，见下）。
- **半身到七分身**，人物占画面 70% 左右，视线（或身体朝向）略偏向画面内侧；脸要有表情、有故事感，不要呆站。
- 背景是**该角色身世里的场景**，用水墨 / 淡彩虚化处理，不要抢人物；留出画面下方约 15% 的暗部（UI 要压文字）。
- 不要文字、不要印章、不要边框、不要 UI。
- **保持角色识别度**：下面每个角色都标了「必须保留」的特征（发型、主色、标志物），这些和局内精灵、小镇精灵、选人全身像是同一个人，**不要换掉**；新增的是身世细节和场景。

### B1. 武者（`fist_hero.jpg`）——北地小武馆的出师弟子
**身世**：破落小武馆长大，师父只教站桩、吐纳和一口不肯认输的气；武馆被山贼烧掉，师父把最后一本拳谱塞给他：「拳不是用来杀人的，是用来护住身后人的。」
- **必须保留**：青绿色短打、红围巾、高马尾带金冠、拳掌架势。
- **身世细节**：双手缠着**磨旧的白布绷带**（指节处有渗出的旧痕）；腰间别着一本**边角烧焦的旧拳谱**（用布包着）；围巾上有一处被火燎过的焦边；脸上有一道新擦伤。
- **场景**：背景是**烧塌的武馆**——半截木梁、烧黑的练功桩、一面残破的武馆旗，晨雾里还有几缕青烟；人物站在废墟前，一拳在前、一掌护身，目光坚定，像护着身后的人。
- **色调**：青绿 + 烟灰 + 一点暖红（火光余烬），整体偏沉静。

### B2. 剑侠（`sword_hero.jpg`）——江南剑庐的少庄主，寻找最强的剑
**身世**：胜过全庄剑师后忽然觉得空，抛下家业、一身白衣腰挂酒葫芦出门，找「什么才是天下最强的剑」；传闻华山绝壁上有无敌剑客的遗刻「独」字与「无招」。
- **必须保留**：白衣青绿镶边、青色发带、腰挂酒葫芦、单手持剑。
- **身世细节**：**剑还未出鞘一半**（半拔），眼神带着一点迷惘和向往；衣袂上有赶路的尘土；腰间系着一枚**江南剑庐的小木牌**（不要写字）；酒葫芦有磕碰。
- **场景**：背景是**云雾中的华山绝壁**，崖壁上隐约有一道巨大的剑痕和一个模糊的石刻字（**只是一个很大的笔画轮廓，不要出现可读文字**），人物站在崖前石阶上仰望。
- **色调**：白 + 青绿 + 云雾灰蓝，明亮清冷。

### B3. 刀客（`blade_hero.jpg`）——漠北马帮的刀手
**身世**：护镖三十载没丢过一趟；同伴替他挡下致命一刀，死在他怀里。赤金披风是亡友遗物，是亡友生前最爱的颜色。越是流血越清醒，想知道这把刀能劈开多少不公。
- **必须保留**：黑衣、斗笠（背在身后或压低）、赤金披风、宽背大刀、桀骜的神情。
- **身世细节**：披风下摆有**一道旧刀痕和补过的针脚**（这是亡友替他挡刀留下的）；大刀的刀背上系着一条**褪色的红布条**；脸上有风沙刮出的细纹，笑里带着苦；手背上有未愈的伤。
- **场景**：背景是**漠北黄昏的沙丘和一队远去的驼影**，风沙把披风吹得猎猎作响，远处一个小小的孤坟（一块插在沙里的木牌）——人物没有看它，但画面里有它。
- **色调**：黑 + 赤金 + 沙黄 + 落日橙，浓烈、孤独。

### B4. 杨家将（`spear_hero.jpg`，新；与 A1 第 1 项是同一张，只画一次）——前杨家军唯一的生还者
**身世**：杨家军镇守北疆三代，一道假军令把七千将士送进绝境；他是唯一爬出尸山的人，长枪折断，只剩半截白蜡棍；朝廷要追封，他没有领；埋了军牌，换上粗布衣，在江湖里走动，一面追查真相、一面替路过的百姓挡几刀；那份正直仍不许他对不平之事转身。
- **人设（必须和 `docs/art_spec9_yangjiajiang.md` 一致）**：中年，棱角分明，眉间 / 脸颊一道旧疤，目光沉静不带笑；黑发粗布头巾束起，鬓角几缕白发；灰蓝色粗布外袍（有补丁），左肩 / 护臂是**残破的银白军甲**（有磕碰裂痕）；腰间磨旧的军牌（无字）；右手一杆红缨长枪（枪身深木色、银亮枪头），背后斜背一根白蜡长棍。
- **身世细节**：军甲上有**一道深深的刀痕**；红缨已经褪成暗红、末端被血浸过；披风 / 外袍被风吹起；人物微微侧身，一手握枪，另一手**搭在背后的棍上**（枪棍兼用）。
