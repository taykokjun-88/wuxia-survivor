## 二、已完成（按模块）
### 玩法与系统
- 四个职业：**武者 / 剑客 / 刀客 / 杨家将**，每职业 9~10 个招式、专属机制（寸劲 / 九变 / 刀魂 / 枪势·棍势·格挡）。
- 三张地图：**黑风寨 / 赤焰巅（原光明顶）/ 海棠屿（八卦阵）**，各有小怪时间表、3 个小 Boss + 大 Boss、限时通关；华山论剑 / 第 4~6 关隐藏为「？？？」。
- 升级系统：品质（白蓝紫金）× 10 次强化、心法同修、秘籍三选一、局内抽卡时**提示天赋树强化**。
- 局外成长：修为 / 等级 / 属性点 / 装备 / 银两 / 强化；局外 1~15 级修为 +50%。
- **天赋树（RO 式，四个职业都做完）**：每系 50 点、总容量 150 点、满级最多 99 点 + 第 100 点「极意」；前置（≥1 点 / 点满）+ 层门槛 3/6/9/15/21/25/36（普通节点门槛不超过本链已点点数，可先单点一条链；终极 25、巅峰 36）；约 150 个新机制，全部有测试。
- 本阶段刚改的数值：Boss 血量（小 ×1.25 / 大 ×3.125）；**刷怪速度**开局 0.8/秒按曲线升到 9.5/秒，同屏上限 240；**局内怪经验 +30%**；通关用时下限 = 大 Boss 现身 +1 秒（修「成绩无效（通关）」）。
- **八卦阵（海棠屿）新规则**：生成 10 秒 / 冷却 10 秒；第 3、6、8 秒随机重排所有门；玩家在阵内待满 8 秒「阴阳八卦，唯我破阵」获得益处 buff 的 50% 直到下次阵法出现；对玩家和怪物都生效（小 Boss 在凶门里只吃一半的百分比掉血）；**大 Boss 现身后不再生成、在场的收掉**；金（生门）/ 绿（益处）/ 黑红（四凶门）大字徽章，不写说明；范围 ×2（半径 860）。
- **整局破阵彩蛋**：如果整局每一轮八卦阵都触发了「唯我破阵」，大 Boss 现身时——**杨家将**说「我已经看破了你的阵法。且看看我的阵法如何」并出现大字「阵法·杨家无敌」：Boss 不再生成罡气、防御 −30%、攻击 −20%、移速 −50%；**其他职业**触发「真·唯我破阵」：60 秒的唯我破阵 buff。
