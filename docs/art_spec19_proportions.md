# 美术计划书 19（给 Gemini）：武者、杨家将立绘腿太短——重画（比例修正）

> 反馈：武者和杨家将的立绘 / 选人全身像**身材比例难看，腿短**。对照剑客、刀客的图确实如此：这两位是「上身壮、裤子宽大、小腿和靴子被衣摆遮住」，视觉上腿只占身高的三分之一出头。要重画。

## 一、统一的比例硬指标（四个职业都以此为准）
- **八头身**：头顶到脚底 = 8 个头长。
- **腿长占身高 ≥ 50%**：裆部（两腿分叉处）必须在**身高的中点或略高于中点**；膝盖在身高约 **28%** 处；脚踝在约 **5%** 处。
- 大腿与小腿长度**接近相等**，小腿不要被宽大的裤脚 / 靴筒盖掉；**脚踝要露出**，鞋子要有明确的脚型。
- 肩宽约 **2~2.3 个头宽**（不要超过 2.5），腰比肩窄，**不要**过度夸张的肌肉。
- 手长到大腿中部，手掌约等于脸长。

## 二、武者（`fist_hero.jpg`、`charselect_fist.png`）
**现在的问题**：上半身肌肉过大、肩过宽，裤子肥大且膝盖以下短，靴子很矮，整体下沉。
**要求**：
- 肩宽收窄一些，手臂粗细合理（有力但不要健美运动员式）；
- **裤子改成较合身的绑腿裤（束脚）**：大腿略宽、小腿收窄并有绑带，让腿的长度一眼可见；
- 靴子 / 布鞋要有明确鞋型；
- **姿势保持**（一拳在前、一掌护身），但**站得更直、重心不要压太低**，两脚间距收小一些，避免把腿「缩短」。
- 服装、围巾、金冠、绷带、旧拳谱、脸上擦伤、场景（烧塌的武馆）都不变。

## 三、杨家将（`spear_hero.jpg`、`charselect_spear.png`）
**现在的问题**：长袍下摆和宽裤把腿遮住，小腿缠布后很短，两根长杆交叉又挡住了腿部，整体显矮。
**要求**：
- **长袍下摆缩短到膝盖以上**（或开衩），露出**完整的小腿和脚踝**；裤子改成**束脚裤 + 绑腿**，不要太蓬；
- 两件长兵器（枪、棍）**不要交叉遮住腿**：枪握在手里斜指向上，棍**斜背在背后**，只露出上端一小截；
- 站姿略分腿、重心稳，但腿要显长；
- 服装、红头带、护肩甲、腰带、绷带、脸上旧疤、场景（雁门关残楼）都不变。

## 四、登录封面（`login_cover.jpg`）里的这两人（下一版封面一起改）
