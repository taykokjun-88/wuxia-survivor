## 1. 定位：一个职业，两条路
| 流派 | 一句话 | 核心资源 / 机制 |
|---|---|---|
| 武者 | 内力深厚的近身拳掌 | 内力三境、蓄劲 / 寸劲 |
| 剑客 | 轻快多变（独孤九剑另论） | 移速换攻速 |
| 刀客 | 大开大合、越战越勇 | 刀魂、耗血、撕裂 |
| **杨家将（长兵）** | **一寸长一寸强。两条路：枪=灵动控距，棍=刚猛抗压** | **格挡（全派）+ 枪势（靠移动）/ 棍势（靠近身与格挡）** |

起手招式只有两个，决定玩家主走哪一路：**杨家枪法（枪路）**、**少林棍法（棍路）**。升级时也能混学另一路的招式，但「势」的收益按各自的招式生效。

**杨家将通用被动**：招式射程 +10%；**格挡几率初始 20%，格挡成功 = 本次伤害完全免疫**（飘「格挡」）；**格挡特效：主角挥棍划半个圈（半圆弧光），并把周围近身的敌人稍微震退**；格挡几率上限 **70%**（所有来源——招式强化、心法、天赋、装备词条——合计封顶）。局内要有提高格挡的途径：棍路几个招式的强化方向、一个专门的「铁壁」升级方向、装备词条（格挡 +%）、天赋（刚系）。
**枪路被动（灵动）**：移速 +8%；穿透 +1；连击数加成（见下）。
**棍路被动（刚猛）**：暴击率 +10%、暴击伤害 +25%；额外格挡几率 +10%（总计 30%，仍受 70% 上限）；被 3 个以上近身敌人包围时不再被「围殴」减速 / 硬直，棍法伤害 +15%（不畏近身）。

## 2. 两个「势」
### 枪势：越跑越凶，「突远」与「突破」
- **攒势**：靠**移动**——每移动 100 像素 +10 势（风筝 / 走位本身就在攒），受击不掉势。
- **远射程增伤（枪尖）**：枪法命中处在射程外 35%（枪尖）的目标 → 伤害 +45%、露出「破绽」2 秒；贴身命中 −10%。命中枪尖时飘「枪尖」。
- **连击**：2 秒内连续命中累计连击数，每 5 连击 +6% 伤害（最多 +30%）；每满 10 连击触发一次「枪影」：对周围最多 3 个目标各追加一枪。
- **势满 100 → 突破**：下一次枪法变为「游龙突」——枪手向前冲出约 320 像素，沿途 0.4 秒无敌，贯穿路径上所有敌人（伤害 ×1.8，必暴击，枪尖加成全程生效），冲出后势清零。灵动的核心就是「冲出包围」。
- 枪路的「多目标」：枪法的穿透数、同时攻击的目标数是增长方向（升级方向与天赋都围绕「更多目标」）。

### 棍势：越被围越猛，近身横扫
- **攒势**：命中**近身目标**（120 像素内）每次 +2；成功格挡一次 +10；被近身攻击命中一次 +5。
- **势满 100 → 横扫千军**：下一次棍法变为超大范围横扫（半径 ×2、伤害 ×2.5、必暴击、强击退），打完势清零；横扫时 0.5 秒内格挡几率 +50%。
- **暴击与格挡**：棍路的升级方向与天赋围绕暴击、暴击伤害、格挡几率、受击回复。

### 无名枪法（枪路的重炮）
- **获得方式（隐藏武功）**：不是必学，也不会出现在普通升级卡里；它是杨家将的**特殊隐藏武功**——**越早拿到，越能多打几下、升更多级，是打 Boss 的神功**。建议获得方式：杨家将角色每次升级（局内 3 级起）有 **3% 几率**出现一张金框「隐藏武功」卡，福缘每 +10% 额外 +1%，上限 8%；**局内 12 级仍未出现则必出一次**（保底）。占一个招式槽。出现几率只有这一条，没有别的获得途径。
- **定位**：单体、中距离（射程 250）、**全游戏所有职业所有技能里基础伤害最高**（定为 **330**，高于玄铁重剑 273 / 倚天剑 262）。
- **破防**：命中**无视目标 50% 防御**，并使目标**防御 −30%**（5 秒）。
- **冷却**：**固定 10 秒，任何手段（冷却缩减、心法、天赋、装备）都不能降低。**
- **目标优先级**：优先攻击 **Boss（大小 Boss）> 精英 > 其他**，射程内没有就打最近的敌人。
- **自成长**：每打出 **10 下**升一级：无名枪法 1 → 2 → 3 → 4 → …，每级基础伤害 **+20%（按初始基础伤害计）**，没有等级上限（设一个很高的安全上限，如 Lv30）。招式名字随等级显示「无名枪法 N」。
- **强化方向（升级卡里）**：**不会**出现增加打击目标、增加伤害、增加范围。只会出现：
  - **暴击**（暴击率 +%）
  - **连击**（几率连续出招两次，第二次 60% 伤害）
  - **贯穿**（破防强化：无视防御的比例 50% → 最高 90%）
  - **定身**（命中几率让目标定身，时间随强化增长）
  - **破绽**（命中使目标露出破绽的时间 / 增伤）
  这几个都是现有「方向」体系里加 3 个新方向（贯穿 / 定身 / 破绽）实现，不影响其它招式。
- **专属强化「无名之名」（拿到小 Boss 秘籍后）**：打出无名枪法后的 **5 秒内，枪法招式伤害 +30%**（不叠层，每次打出刷新；冷却 10 秒，所以覆盖率约一半）。
- **催动**：必暴击。

## 4. 心法 / 天赋 / 装备
- **心法**：沿用现有心法，把长兵招式加进「同修」名单（每个心法 2~3 个本流派招式）。例如轻身 / 身法类 ↔ 梅花枪法、白马银枪；气势 / 刚猛类 ↔ 降魔杖、少林棍法。具体按现有表对齐。
- **天赋**：沿用「刚 / 柔 / 灵」三系的结构，长兵的覆盖：
  - **灵（枪路）**：左侧强化枪势（攒势速度、突破距离与伤害、枪影数量）；右侧强化枪尖与连击（枪尖区加宽、连击加成上限、破绽时间）。
  - **刚（棍路）**：暴击 / 暴击伤害、格挡几率与格挡回复、棍势攒速、横扫半径。
  - **柔**：通用生存与回复（气血、回复、内力）。
  - **「极」穴位**：**极·万军辟易**——枪路：突破后势只清一半，枪尖区 +50%；棍路：横扫后立刻再攒 40 势，格挡几率 +10%。
- **装备**：武器 10 件「长兵类」（梅花枪、点钢枪、丈八蛇矛、白蜡杆、哨棒、齐眉棍、禅杖、方天画戟、混铁棍……传说：龙胆亮银枪，仅最高档）；其它部位沿用。词条沿用「强化某个招式」的机制，按适配度算分。

## 6. 流派命名建议
现有的是「武者 / 剑客 / 刀客」（人 + 兵器）。长兵同时包括枪和棍，没法像「剑客」那样直接叫。候选：
1. **镖师**（我的首选）：旧时镖局的看家功夫就是「枪棒」，既包含枪也包含棍，又很有江湖味，和另外三派并列也顺口。
2. **枪棒手**：最直白，一看就知道是枪和棍；但「手」字不如另外几个有气质。
3. **长兵客**：沿用现在的名字，加一个「客」，和「剑客 / 刀客」保持一个格式；缺点是「长兵」读起来较生硬。
4. **武师**：枪棍是武师教徒的正宗功夫；但和「武者」太像，不建议。
