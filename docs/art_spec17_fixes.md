## 一、武者（fist）立绘重画——P0

### 问题
`fist_hero.jpg` 和 `charselect_fist.png` 里的人物脸圆、眼大、四肢短、身体小，像十几岁的少年，和剑客 / 刀客 / 杨家将（成年青年）放在一起不协调。登录封面里的武者同样偏幼。

### 要求
- **成年男性（20~25 岁）**，**日系二次元**（不是少年漫画 / 热血漫画风）：**八头身**左右的修长比例、肩宽腰窄、手脚大小自然、脸型偏长、五官成熟（眼睛不要过大，眉眼有神、有棱角）。
- 参照 Drive `yangjiajiang_v3` 里的剑客 / 刀客 / 杨家将立绘的**脸部比例与画风**，四个人放在一起要像同一个系列的同龄人。
- **服装不变**：青绿短打、红围巾、高马尾金冠、缠白布绷带、旧拳谱别在腰间；围巾有焦边，脸上有一道新擦伤。
- 场景不变：创建立绘是烧塌的小武馆废墟（晨雾、青烟）。
- 姿势不变：一拳在前、一掌护身。

| 文件 | 规格 |
|---|---|
| `fist_hero.jpg` | 创建角色立绘，≥ 1200×1600，3:4，底部柔和渐变暗角 |
| `charselect_fist.png` | 选人全身像，**透明底 PNG**，≥ 1024×1280，人物占高 90% |

> 另外：`login_cover.jpg`（登录封面）里的武者也偏幼，下一版封面请一并按成年比例改。

## 二、杨家将战斗精灵——改成正常比例——P0

### 问题
现在 9 个战斗动作都是「头占身高约 40%」的 Q 版（和小镇精灵一样），而剑客 / 刀客 / 武者的战斗精灵是**头占身高约 1/5**、四肢修长的正常比例。放进游戏，杨家将又矮又胖，像别的职业的小弟。

### 要求（对照仓库 `assets/sprites/sword/idle.png`、`blade/idle.png`、`player/idle.png`）
- **头身比约 1:5**（头约占身高 20%），身体修长，手脚比例自然；同样是 **硬边像素、有限调色板、深色 1px 外轮廓**。
- 站直时「发髻顶 → 脚底」固定 **约 300 px（在 1376×768 画布上）**，所有动作同一比例同一画布，脚底对齐，朝右。
- 服装 / 武器设定不变：深藏青补丁长袍、红头带、红腰带、右肩旧银护肩甲、红缨银枪，背后背白蜡棍。
- 动作与帧数不变：每个动作 **1 行 4 帧**。

| 文件 | 内容 |
|---|---|
| `spear_idle.png` | 待机（呼吸起伏，枪缨 / 头带尾摆动） |
| `spear_walk.png` | 行走（步幅明显，枪位置稳定） |
| `spear_thrust.png` | 刺击：蓄势 → 刺出 → 收枪 → 回位 |
| `spear_slash.png` | 棍横扫：蓄势 → 挥出大弧 → 收势 → 回位 |
| `spear_block.png` | 格挡：举棍横挡 → 挥棍半圈 → 震退 → 收势 |
| `spear_dash.png` | 冲刺：前倾，枪向前 |
| `spear_ult.png` | 觉醒大招：举枪蓄力，气浪（只用白 / 淡蓝 / 米黄，不要粉紫） |
| `spear_hurt.png` | 受击：后仰、险些脱手 |
| `spear_death.png` | 死亡：中枪踉跄 → 单膝跪 → 倒下 → 静止（倒地时体积不要缩水） |

**不用重画**：`spear_town_down / up / side.png`（小镇 Q 版保持现状）。
