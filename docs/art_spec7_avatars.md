# 美术需求：角色头像（给 Gemini，共 3 张）

## 用在哪
登录后的**选人界面**：每个角色卡片上方显示该角色**职业的头像**（武者 / 剑侠 / 刀客各一张）。目前用立绘里裁出来的脸占位，图到位后自动替换。

## 要求
- 尺寸：**256 × 256 像素**正方形，png 或 jpg 均可（≤ 100KB）。
- 内容：**半身头像（头 + 肩膀 + 一点武器 / 衣领）**，脸占画面约 55%，居中，正面或微侧 3/4 角度，神态符合职业。
- 风格：和现有立绘一致的**水墨武侠插画**；背景是简单的水墨晕染 / 烟雾，颜色偏暗，不要有文字、边框。
- 人物必须和现有立绘是**同一个人**（发型、服饰、配色一致），参考 `assets/portraits/*_hero.jpg`：
  - **武者 fist**：青绿色短打、红围巾、高马尾带金冠，神情坚毅。
  - **剑侠 sword**：白衣青绿镶边、束发带青色发带，腰挂酒葫芦，神情清朗。可露出一点剑身。
  - **刀客 blade**：黑衣赤金披风、斗笠背在身后、短发，笑容桀骜；可露出一点刀背。
- 圆角 / 圆形裁切由游戏处理，主体不要贴边。

## 文件命名（放到 `assets/avatars/`）
`fist.png`　`sword.png`　`blade.png`

## 提示词模板
> 水墨武侠半身头像，256×256 正方形。人物：{上面的角色描述}，与参考立绘同一人。面部清晰，占画面约一半，居中，背景为淡淡的水墨晕染与烟雾，色调偏暗，无文字无边框。
