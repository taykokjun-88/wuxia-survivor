- 剑侠流派介绍写明两条路线：**独孤九剑流派（前弱后强）** 与 **一般剑法流派（万用）**（创建角色界面、百晓册）。
- **「式」的层数 = 升级次数**：每次升级 +1 层（`tuning.shi_card_gain` = 1），所以不选心法时最快局内 **10 / 19 / 28 级**达到 9 / 18 / 27 层（破兵微步 / 万法皆破 / 真·独孤九剑）。**品质**（白蓝紫金）只给这一式额外威力（`shi_bonus`，每档 +0.5 层，取整；`shi_lv()` = 层数 + 加成，各式效果按它结算），**不计入总层数和门槛**。小 Boss 秘籍：层数 +0，只给紫 / 金品质加成。
- 平衡待测：独孤九剑前期更弱、真形态更晚（原先约局内 14 级），请实测手感后再调。
