## 追加（升级强化系统改版，2026-11-20）
- **品质**：每次强化（选一张升级卡 = 强化一次）有品质：普通（白）/ 特别（蓝）/ 优秀（紫）/ 传说（金），概率 50 / 25 / 18 / 7；每高一档强化量 +1 倍（1 / 2 / 3 / 4 ×）。卡片的框和字用品质色。福缘仍会提高优秀 / 传说的出现率。数值：`data.tiers` / `data.directions.*.values`。
- **强化次数**：每个招式最多强化 10 次（`max_upgrades`），每个心法最多强化 3 次（修习 = Lv1，强化后最高 Lv4）；4 个招式 + 2 个心法全部满级共 46 次。
- **起手招式**（9 个）不会出现在升级卡里（`Data.is_starter`）。
- **心法重设计**：10 个心法按流派分（武者：九阳神功 / 北冥神功 / 铁布衫；剑侠：葵花宝典 / 玄冥神功 / 小无相功 / 斗转星移；刀客：易筋经 / 先天功 / 九阴真经），各自有定位，并对应 2~3 个本流派的非起手招式（`xinfa.<id>.skills` / `link`）：学会后这些招式有「同修」加成（伤害 / 冷却 / 范围 / 暴击 / 连击 / 催动消耗 / 减速 / 回血，以及盈境增伤 / 命中回内力 / 破绽 / 撕裂）。心法强度 = 修习 1 份 + 每次强化（品质 + 1）份，强度越高被动、标签加成、同修越强。合璧改成只配同流派内的搭配（10 个）。
- **独孤九剑**：「破 X 式」总层数门槛 9（破兵微步）/ 18（万法皆破）/ 27（真·独孤九剑）；见「计划书 6」一节。
- **初始恢复**：内力回复 12 → 8.4（−30%）；气血回复 0 → 0.2/秒（每 5 秒 1 点）。


## 计划书 6（已实装）
- **另觅机缘**：局外每满 5 级，局内 +3 次重抽升级卡（Lv5=3 次、Lv10=6 次）。选卡界面按钮 / R 键；重抽尽量避开刚才展示的卡；小 Boss 秘籍选卡不可重抽；次数用在 `run_summary.rerolls`。
- **真·霸刀破岳**（刀客）：气血 ≤ 20%（每帧检查）触发，持续 10 秒；期间刀招不扣血（刀魂照涨，按本该耗的血算）、吸血 / 击杀回血 / 自然回复翻倍，触发瞬间 0.5 秒无敌；冷却 30 秒，从状态结束后才开始算。原来的「霸刀破岳」（刀魂满的那一刀）飘字随机显示「霸刀！」或「破岳！」，效果不变。数据：`tuning.true_blade_*`。
- **蓄劲**（武者）：每次出拳掌招式 +3（暴击 +5，每 0.3 秒一次）、盈境每秒 +4，满 100 后下一次出手触发「寸劲震爆」（范围 170、3 倍伤害、强击退、破绽）。HUD：底部居中的劲力条。数据：`tuning.fist_qi_*`。
- **独孤九剑**：门槛 9 / 18 / 27；破兵微步、剑剑破绽（攻防各 −30%，4 秒）、破箭式改为斩落敌方普通投射物（Boss 弹幕标记为不可斩）；27 层后已学的式全部转为近战形态，每一式都写明「普通 / 觉醒」效果；连击几率 45% / 20% / 8%。测试：`TEST_ONLY=plan6`。
