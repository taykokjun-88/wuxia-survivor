# 美术需求：选人界面「帅气高清全身 sprite」（给 Gemini，共 3 张）

## 用在哪
登录后的**选人界面**：五个角色卡片，每张卡片中间放该角色**职业的全身形象**（不再用头像）。要的是一张**重新绘制的、帅气的高清全身角色图**，比现在的立绘更精致、更有气势，一眼能认出是哪个职业。

## 要求
- 尺寸：**512 × 640 像素**（竖版，约 0.8 : 1），**透明背景 png**；如果出不了透明底，用**纯洋红 #ff00ff 底**，我来抠。
- 内容：**全身，从头顶到脚底都在画面内**，站姿帅气，有职业特色的动作姿态（不是呆站），人物占画面高度的 90%，脚底留一点空间；可以带少量光效 / 飘带 / 火花，但**不要大面积背景**（卡片自己有背景）。
- 风格：高清水墨武侠插画 / 精致手绘质感，线条干净、光影立体，和现有立绘是**同一个人**（发型、服饰、配色一致，参考 `assets/portraits/*_hero.jpg`），但画得更精细帅气。
  - **武者 fist**：青绿色短打、红围巾飘扬、高马尾带金冠；拳掌架势（一拳前出、一掌护身），周身青色真气环绕。
  - **剑侠 sword**：白衣青绿镶边、青色发带，腰挂酒葫芦；单手持剑斜指，衣袂飘飘，剑身带淡蓝剑气。
  - **刀客 blade**：黑衣赤金披风、斗笠背在身后；扛着/提着大刀，刀身冒火星，披风被风吹起，笑容桀骜。
- 三张**朝向一致（面向画面中偏右）**、光源一致、风格统一。
- 不要文字、不要边框。

## 文件命名（放到 `assets/char_select/`）
`fist.png`　`sword.png`　`blade.png`
