# V1.0 后端部署、备份与旧存档迁移检查清单（D5）

> 适用对象：Google 表格 + Google Apps Script 后端（`backend/Code.gs`）。每次修改 `backend/Code.gs` 后都必须按本清单执行「新版本部署」，否则线上仍运行旧代码。

---

## 一、部署前备份（约 1 分钟）
1. 打开绑定的 Google 表格 → 菜单 **文件 → 创建副本**，命名为 `群侠千招数据备份_YYYYMMDD_部署前`。
2. 特别确认以下 6 张工作表均在副本中完整保留：`邀请 Invites`、`玩家 Players`、`角色 Characters`、`排行 Scores`、`日志 Logs`、`反馈 Feedback`。

## 二、部署最新 `backend/Code.gs`（约 2 分钟）
1. 本地确认后端单测与数据同步均通过：
   ```bash
   python3 tools/sync_talents.py
   node backend/test/backend.test.js
   ```
2. 在 Google 表格中点 **扩展程序 → Apps Script**，将仓库最新 `backend/Code.gs` 全文覆盖粘贴并保存（Ctrl+S）。
3. **重要**：点右上角 **部署 → 管理部署**（不要点「新建部署」，否则会生成新网址导致 `data/config.json` 失效！）。
4. 点当前线上部署右侧的 **铅笔图标（编辑）** → 版本选 **「新版本」** → 说明填版本号（如 `v0.9-fix-1`）→ 点 **部署**。
5. 回到 Google 表格刷新，点顶部自定义菜单 **武侠后台 → 初始化 / 修复表头**（确保新增列/文本格式生效）。

## 三、上线后 4 项快速验证（约 2 分钟）
1. **核对代码版本**：浏览器直接打开 `<api_url>?action=ping`，确认返回 JSON 中：
   - `"ok": true`
   - `"rev": "v0.9-fix-1"`（与 `backend/Code.gs` 第 15 行 `CODE_REV` 完全一致）
   - `"schools": ["fist", "sword", "blade", "spear"]`
2. **验证海棠屿通关上传**：确认不再出现 `成绩无效（通关）`（`MAPS.taohua.minWin = 841`）。
3. **验证天赋树保存**：用任一角色在武馆点新 RO 天赋树并点「保存」，刷新页面重登确认加点保留。
4. **验证安全与排行榜**：确认分地图榜（黑风寨 / 赤焰巅 / 海棠屿）正常加载；若执行新赛季「清空排行榜」，分地图榜也会同步清零。

## 四、旧存档迁移注意事项（告知测试玩家）
- **旧版 33 点/系天赋树 → 新版 150 点 RO 天赋树**：旧节点 ID 属于 `legacy` 组，客户端加载到新树界面时会把旧点自动视为未分配（总点数不变 = 局外等级 × 2），玩家在武馆重新点新树保存即可，**不会丢失局外等级、装备、银两或通关记录**。
- **旧版 5 档装备稀有度**：服务器端 `readState()` 会自动将旧 5 档编码降为第 4 档（传说），保留原强化等级。
- **旧版单角色账号**：首次登录时 `ensureChars()` 自动将旧玩家行迁移为该账号的第 1 个角色（角色名 = 账号昵称），只迁移一次。
- **旧版无 `mapBests` 成绩**：玩家首次提交任意一局成绩时，自动将历史总最高分迁移为黑风寨成绩。

## 五、回滚方案
若部署后发现异常：在 Apps Script → **部署 → 管理部署 → 编辑**，将版本切回上一个正常版本号并点部署（无需改客户端网址）；如发生表数据损坏，从步骤一创建的 Google 表格副本恢复对应工作表即可。
