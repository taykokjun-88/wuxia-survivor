# 第 3~6 关设计草案（供审核，尚未实现）

沿用现有框架：每张地图 = 时间轴（3 个小 Boss + 1 个大 Boss + 限时）+ 5 种杂兵 + 地图专属机制 + 修为 / 掉落设置。数值按新的局外曲线与装备分（5 件普通≈22、5 件特别≈39、5 件稀有≈77、传说更高）排。

- 推荐装备分到 140 以上基本要求同一招式词条集齐（联动加成），符合「集齐五件理应有这样的表现」。

## 各关特色（每关一个新机制，避免只是数值变大）

**3 少林寺·藏经阁**：杂兵以高防御武僧为主，罡气 / 护盾多——对刀客（破盾）有利、对拳掌（寸劲破防）也有利，剑客靠破绽。机制：「钟声」——每隔一阵全场敌人获得短暂护盾，必须在钟声间隙爆发输出。小 Boss：扫地僧三兄弟式；大 Boss：达摩院首座（金钟罩 + 罗汉阵召唤）。

**4 桃花岛**：机制「奇门阵」——地面周期性出现可进入的阵眼（进入获得短暂 buff，但敌人会往阵眼聚），迫使走位。杂兵偏远程 / 毒雾。大 Boss：黄老邪式——乐声预警（音波圈）+ 瞬移。

**5 万安寺 / 绝情谷**：机制「情花」——地面毒花区域持续存在、会随时间扩大，限制活动空间；杂兵成群、精英多。大 Boss：国师 / 公孙止式，带手下护法同时在场。

**6 华山论剑**：最终关。五位宗师（东邪西毒南帝北丐中神通式）作为 5 个小 Boss 依次出现，每个有自己的招式组；最后华山之巅的大 Boss 是「前面五位招式的合体」。机制：每击败一位宗师，自己获得一个短暂「悟道」增益。

## 设计思路：每一关只加一个「新压力」，难度和地图主题一起爬升
| 关 | 主题 | 新压力（核心机制） | 主要考验 |
|---|---|---|---|
| 1 黑风寨 | 山贼 | 无（教学） | 基本走位、选卡 |
| 2 光明顶 | 五大派围攻 | 杂兵种类多、血量随时间 ×8 | 打得过杂兵潮 |
| **3 少林寺·藏经阁** | 佛门，护体深厚 | **钟声护盾**：全场敌人周期性获得护盾，要抓钟声间隙爆发 | 爆发输出 / 破盾 |
| **4 桃花岛** | 奇门遁甲、毒 | **奇门阵眼**：地面周期出现阵眼，进入有增益但敌人往里聚 | 走位取舍 |
| **5 万安寺** | 朝廷鹰犬 | **箭雨与重甲**：官兵远程齐射 + 高防御，限制活动空间 | 躲预警 + 破防 |

## 第 3~5 关的角色阵容（沿用游戏的谐音梗风格，避开版权原名直用）
- **3 少林寺**：杂兵＝武僧、护院僧、戒律僧、罗汉、铁头僧；小 Boss＝空蚊大师、空痣大师、玄瓷方丈；大 Boss＝**扫地增**（藏经阁扫地的无名老僧，金钟罩 + 罗汉阵召唤）。
- **4 桃花岛**：杂兵＝哑仆、家丁、药童、毒蝎（毒雾）、机关人偶；小 Boss＝陆乘疯、武修文、周百痛；大 Boss＝**黄荣**（岛主之女，奇门阵眼 + 瞬移 + 乐声音波）。*（黄药狮留给第 6 关当「东邪」，避免重复。）*
- **5 万安寺**：杂兵＝官兵（弩手）、重甲兵、大内侍卫、玄冥鹰犬、番僧；小 Boss＝阿大、阿二、阿三（三名护卫，成组出现）；大 Boss＝**金轮发王**（国师，五轮 + 召唤官兵）。*（这一关还能呼应杨家将的背景：朝廷奸佞的鹰犬，可以给杨家将角色加一句专属对白。）*
- **6 华山论剑**：五个小 Boss＝东邪黄药狮、西毒欧阳疯、南帝一灯、北丐洪七工、中神通王重阳（各自一套招式）；大 Boss＝**华山之巅的无名老者**（前面五位招式的合体，打到最后才揭示身份，可以接「独孤九剑」的彩蛋）。限时更长（180 秒）。
