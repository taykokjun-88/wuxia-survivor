## 各关特色（每关一个新机制，避免只是数值变大）

**3 少林寺·藏经阁**：杂兵以高防御武僧为主，罡气 / 护盾多——对刀客（破盾）有利、对拳掌（寸劲破防）也有利，剑客靠破绽。机制：「钟声」——每隔一阵全场敌人获得短暂护盾，必须在钟声间隙爆发输出。小 Boss：扫地僧三兄弟式；大 Boss：达摩院首座（金钟罩 + 罗汉阵召唤）。

**4 桃花岛**：机制「奇门阵」——地面周期性出现可进入的阵眼（进入获得短暂 buff，但敌人会往阵眼聚），迫使走位。杂兵偏远程 / 毒雾。大 Boss：黄老邪式——乐声预警（音波圈）+ 瞬移。

**5 万安寺 / 绝情谷**：机制「情花」——地面毒花区域持续存在、会随时间扩大，限制活动空间；杂兵成群、精英多。大 Boss：国师 / 公孙止式，带手下护法同时在场。

**6 华山论剑**：最终关。五位宗师（东邪西毒南帝北丐中神通式）作为 5 个小 Boss 依次出现，每个有自己的招式组；最后华山之巅的大 Boss 是「前面五位招式的合体」。机制：每击败一位宗师，自己获得一个短暂「悟道」增益。

## 第 3 关：桃花岛·奇门遁甲
- **八门机制**：以玩家为中心 / 或固定在地图中心的一张八卦盘（地面贴花），分为八个扇区：**休、生、伤、杜、景、死、惊、开**。每隔约 20 秒，八个门的位置重新洗牌，洗牌前 3 秒用颜色预警。
  - 吉门（站上去有益）：**生门**——每秒回复气血；**开门**——移速与冷却缩减 +；**休门**——获得护盾；**景门**——伤害 +25%。
  - 凶门（站上去有害）：**伤门**——持续掉血；**死门**——每秒重伤 + 减速；**惊门**——被定身 / 惊吓（短暂打断）；**杜门**——封内力（不能催动 / 爆发）。
  - 敌人也受八门影响：站在凶门的敌人会受到一点伤害——给玩家「把敌人引到凶门」的玩法。
- **杂兵**：哑仆、家丁、药童、毒蝎（毒雾）、机关人偶；小 Boss：陆乘疯、武修文、周百痛；大 Boss：**黄荣**（奇门阵眼 + 瞬移 + 乐声音波）。（黄药狮留给第 6 关。）
- **美术**：地图贴花（八卦盘、桃林、青石）、5 种杂兵 + 4 个 Boss 精灵、八门地面特效 8 种（可复用同一底图 + 程序染色）。

## 第 4 关：大破少林十八金银铜阵
- **阵法机制**：一队 **18 人的阵**：**12 铜人 + 5 银人 + 1 金人**（金人是阵眼）。阵内的人彼此**共享护盾 / 分担伤害**；阵型按固定节奏旋转 / 收缩 / 拉开（预警亮出下一次变阵的落点）。
  - **破阵**：先打银人（破掉联防）→ 最后打金人（阵眼），金人一倒全阵崩溃（所有人定身 3 秒 + 受伤 ×1.5）。
  - 阵不破，铜人的伤害减免随存活人数提高；所以火力要集中、不能乱打。
- **关卡节奏**：三名小 Boss 就是三次**破阵**战：「铜阵」（12 铜人 + 阵眼）→「银阵」（银人为主，攻击更强）→「金阵」（金人为阵眼，阵型最复杂）；最终 Boss：**达摩院首座**（带领完整的 18 人阵，同时自己有金钟罩 + 罗汉拳）。
- **杂兵**：武僧、护院僧、戒律僧（铁棍）、罗汉、铁头僧。
- **美术**：铜人 / 银人 / 金人精灵（同款不同色）、阵眼金人光环、变阵预警贴花、少林寺地砖与石狮 / 塔林障碍、5 种杂兵 + 小 Boss + 首座。

2. **万安寺**：朝廷鹰犬，机制「箭雨与重甲」（和雁门关重叠较多，可合并）。

## 第 6 关：华山论剑 × 侠之大者

# v4（按你的决定）：第 5 关 = 雁门关；第 6 关 = 联盟对抗（不再「守护」）

## 第 5 关：雁门关
- 北疆古战场，杨家军覆灭之地。
- **机制：烽火与箭雨**：官兵与敌军远程齐射，地面有「万箭」预警线（沿用现有预警圈 / 线 / 扇形的施法锁定规则）；烽火台被点燃时场上增援一批敌人，毁掉烽火台（打它几下）可以取消增援。
- **杂兵**：契丹骑兵（冲锋）、弩兵（箭雨）、重甲兵、叛将亲卫、战鼓手（敲鼓给周围敌人加攻）；**小 Boss**：三名敌军将领（左路 / 中路 / 右路）；**大 Boss**：敌军统帅（谐音梗名字实现时再定）。
- 杨家将角色在这一关有专属对白（开场 / 击败大 Boss 后）。
- 适合局外 Lv34~45，推荐装备分 140（草案）。

## 第 6 关：华山论剑 × 侠之大者——联盟对抗
**为什么放弃「守护道友」**：生存类游戏里要保护一群会被击倒的友军很难做好，容易变成负担。改为**盟友自己能打**，玩家和盟友一起对抗敌人。

### 盟友
- 出场：**除了玩家当前职业以外的其他职业**各出现一名：玩家是武者 → 出现剑客、刀客、杨家将；玩家是剑客 → 武者、刀客、杨家将；以此类推（共 3 名盟友）。
- **都是满级（Lv50）、高装备**：数值按「满级 + 五件稀有以上词条装备」的水平给，在这一关里是强力输出，但**不是无敌**。
- **不会让关卡失败**：盟友被打倒后原地倒下（变灰），15 秒后满血复活；倒下期间场上少一份火力，玩家自己仍然是胜负关键（玩家死亡才算失败）。
- 盟友 AI（脚本化，不用完整的升级系统）：靠近最近的敌人 / 优先打 Boss；每个职业 2~3 种固定招式，招式表现直接复用该职业的现有特效与精灵（武者：拳掌 + 寸劲；剑客：连斩 + 独孤剑气；刀客：霸刀劈 + 撕裂；杨家将：枪刺 + 棍扫 + 格挡反击）。
- 盟友的名字：沿用职业名（如「武者」「剑客」），可以以后再起名字。

### 敌人：Boss 车轮战
- **每 15~30 秒投入 2 个单位**——从「过去打过的」小 Boss 和大 Boss 里抽（第 1~5 关的全部小 Boss / 大 Boss 都在池里），一次两个；数值按这一关的难度缩放（盟友有火力，所以 Boss 血量比单挑时更高，保证打 15 秒以上）。
- 杂兵正常刷新（密度比其它关低一些，让 Boss 是主角）。
- **终局**：计时到点（约 12 分钟）出现**最终 Boss**——幕后黑手（伪造军令、勾结外敌的奸佞权相），带着前面的大 Boss 当护卫；击败即通关。
- 「侠之大者」在这里的含义：你和你的盟友、不同的流派并肩作战，为同一件事。

### 实现工作量（比前几关大）
1. 盟友单位（`AllyUnit`）：移动、攻击、血量、倒下 / 复活、绘制（复用精灵）。
2. 4 个职业的脚本化攻击（各 2~3 招）。
3. Boss 车轮战调度（池、间隔、缩放）。
4. 对「友方」的伤害归属与统计（击杀数 / 得分是否算盟友）——建议只算玩家自己的，盟友的伤害不计分、不掉修为（避免被「挂机」刷）。
5. 关卡数据与测试。
- 建议放在第 3~5 关做完之后。
