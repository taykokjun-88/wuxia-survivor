1. **文件名按 id 命名**；不要加版本后缀、不要随机名。
2. **纯 #FF00FF 单色背景**（精灵 / 特效 / 小镇），整张同一颜色；不要方块、渐变、阴影、描边里混洋红。透明底的图（选人全身像、图标）直接给透明 PNG。
3. **分辨率**：立绘 ≥ 1200×1600；精灵 / 特效每帧 ≥ 256 px；胜负图 ≥ 2752×1536。
4. **每个任务先发 1 张「设定图」给我确认，再批量画**（见第一节），避免整批画完发现衣服不对。

## 三、杨家将局内精灵（像素风）——P0，整套重做

> 规格：每个动作 **1 行 4 帧横排**，帧等宽（≥ 256×256 格），**朝右**，脚底对齐，**同一画布比例**（所有动作里站姿的头到脚高度一样，不要某些动作画大 / 画小），纯 #FF00FF 底。

| 文件名 | 动作 | 要点 |
|---|---|---|
| `spear_idle.png` | 待机 | **呼吸起伏**：身体上下 1~2 像素、衣摆 / 红缨 / 头带尾摆动，4 帧循环（v2 的 4 帧几乎一样，没动感） |
| `spear_walk.png` | 行走 | 两腿交替，枪平端或斜扛，**枪位置稳定**，只有腿和身体在动；4 帧循环 |
