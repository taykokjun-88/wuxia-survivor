# 《群侠千招》V1.0 计划书

> 现状：**V0.9**（2026-11）。四个职业（武者 / 剑客 / 刀客 / 杨家将）、三张地图（黑风寨 / 赤焰巅 / 海棠屿）、新天赋树（RO 式，每职业 150 点容量）、重画的角色 / 特效 / 小镇 / 图标、新音效 v2 都已接入，**但数值是初稿、美术没有系统走查、音乐音效的版权没有清完**。
> 路线（你定的）：**强度平衡 → 美术检查 → 音乐 / 音效版权与重置 → V1.0**。计划**下个星期开始执行**。
> 标记：【我】我来做；【你】需要你试玩 / 决定；【Gemini】需要 Gemini 出图 / 查证 / 生成。

## 一、V1.0 的出口标准（全部满足才发 V1.0）
1. **平衡**：四个职业 × 三张地图，机器人 + 真人都能通关，且任何一条构筑不碾压（见 A 线指标）。
2. **美术**：没有名称 / 图 / 立绘 / 特效对不上的资产；没有错字、缺字、溢出；iPad / 手机竖横屏都走查过。
3. **音频**：所有进游戏的音乐 / 音效都有明确来源和许可，**没有 CC BY-NC**，需要署名的都已署名；AI 生成的如实披露。
4. **技术**：全套测试通过；真机（iPad / 手机）触控走查；网页包 ≤ 70 MB；后端已部署、旧存档迁移无误。
5. **文档**：致谢页、版本号、手札（游戏内说明）与实际一致。
