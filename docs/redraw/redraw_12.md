## 一、硬性规则（最重要，违反就无法接入）
1. **角色一致**：每个文件里的角色，必须和**同名循环动画（现有的 `<id>.png`）里的角色是同一个人**——脸、发型、服装、颜色、武器、体型、头身比（约 1:4.3 的 Q 版）全部一致。
   - 做法：**把对应的现有循环条带（Drive `redraw_07/08/09` 里的 `<id>.png`）作为参考图直接贴给你的绘图工具**，再让它画「同一角色的攻击动作」。不要根据名字重新设计。
2. **画风一致**：RO 式 Q 版，柔和手绘、大眼、轮廓是该部位的深色。**不要**写实、不要暗黑、不要成年比例。
3. **规格不变**：每帧 256×256，纯 `#FF00FF` 单色背景（或透明底，二选一，**同一批保持一致**），人物站直约 120 px，脚底距格底 16 px，朝右，不画地面阴影。
4. **条带里只画人物和手里的武器**：
   - 不画飞出去的东西（刀光 / 弧光 / 飞刀 / 箭 / 铁球 / 勺子 / 暗器）和残影；这些由游戏特效层负责；
   - 武器和身体相连的部分可以画，**不要出现与身体断开的碎块**；
   - 画面内容**必须完整落在格子里**，离左右边缘至少 16 px，不能被格子边界切断。
5. 帧数、帧顺序沿用计划书 7、8、9 里的规定（小怪攻击 4 帧：蓄势 → 出手 → 最大伸展 → 收势；小 Boss / 大 Boss 攻击 6 帧）。
