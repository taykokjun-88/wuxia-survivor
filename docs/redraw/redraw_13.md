# 重置画面计划书 13（给 Gemini）：怪物攻击条带第三次——「同一个角色」的攻击动作

> 背景：计划书 11、12 交付的攻击条带，我逐个对比了现有循环条带，**只有 3 张能用**（铁甲喽啰、枯杖疯叟、泼油使者）。其余的是**另一个人**：画风是 Q 版，但脸、发型、衣服颜色、武器全都变了。
> 本计划书只要求一件事：**每个攻击条带里的人，必须和同名循环条带里的人是同一个人。**

## 一、做法（必须照做，不要凭名字重新设计）
1. 打开 Drive 里对应的**现有循环条带**（`redraw_07 / 08 / 09` 里的 `<id>.png`，4 帧）。**把它作为参考图直接交给绘图工具**，提示词写：
   > "Same character as the reference image, same face, same hairstyle, same clothes and colors, same weapon, same body proportions and art style. Only change the pose into: <动作>. Keep the character the same size as in the reference. Pure #FF00FF background."
2. **不要换衣服、不要换颜色、不要换武器、不要换性别 / 年龄、不要换头身比。** 只改姿势。
3. 每一帧都要和参考图里的人对得上：发带 / 发型 / 衣领 / 腰带 / 靴子 / 武器的颜色和形状一致。
4. 画完请自查：**把攻击条带第 1 帧和循环条带第 1 帧并排放大，一眼能认出是同一个人，否则重画。**

## 二、通用规格（同前几份计划书）
- 每帧 256×256，纯 `#FF00FF` 背景（整份同一个颜色），人物**站直约 120 px 高**（和循环条带里人物同样大小，不要画得比参考图大），脚底距格底 16 px，朝右，不画地面阴影。
- **条带里只画人物和手里的武器**：不画飞出去的刀光 / 弧光 / 飞刀 / 箭 / 铁球 / 勺子 / 暗器 / 残影；武器和身体相连的部分可以画，不要有与身体断开的碎块。
- 内容完整落在格子里，离左右边缘至少 16 px，不被格子边界切断。
- 帧数：小怪 4 帧（蓄势 → 出手 → 最大伸展 → 收势），小 Boss / 大 Boss 6 帧。
