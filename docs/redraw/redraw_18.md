# 重置画面计划书 18（给 Gemini）：武者 sprite 逐帧检查的修正

> 来源：用户逐帧检查武者全部 sprite（对照图见当时发的 `fist_*.png`）后的问题。**要求：只重画下面列出的帧，其余帧保持不变；重画的帧必须和同一动作的其它帧是「同一个人」**（同发型、同服装、同配色）。
> 规格：每帧 156×156，透明底（或纯 `#FF00FF` 单色底），脚底位置、人物大小与相邻帧一致；文件名沿用原名，整条横向拼接。

## 一、局内武者：缺刘海的帧（P0）
参考：行走 / 出拳等其它帧——黑色长发束成高马尾，**前额有一缕刘海**（遮住额头两侧），发顶金色小冠饰。
| 文件 | 帧 | 问题 |
|---|---|---|
| `idle.png`（待机） | 第 2 帧 | 没有刘海 |
| `dash.png`（冲刺 / 轻功） | 第 2 帧 | 没有刘海 |
| `ult.png`（真气爆发） | 第 2、3 帧 | 没有刘海 |
> 这几帧的姿势、特效、手脚动作**不要改**，只补上刘海（头发的其余部分保持）。

## 二、小镇武者：配色和局内武者不一致（P0）
文件：`assets/town/hero/hero_down.png`、`hero_side.png`、`hero_up.png`（各 4 帧，192×192）。
问题：**手环（护腕）、裤子 / 裹腿、腰带、鞋子的颜色**和局内武者不一样。请以局内武者为准统一：
- 上衣：青绿色短打（与局内一致）；
- 裤子：青绿色灯笼裤，小腿白色布条裹腿；
- 腰带：红色宽腰带；
- 手环 / 护腕：白色布条缠手；
- 鞋子：深褐色布鞋；
- 围巾：红色（飘带）；
- 发型：高马尾 + 前额刘海 + 金色发冠饰。
> 参考图：局内行走 / 待机帧（`assets/sprites/player/walk.png`、`idle.png`）；三个方向（朝下 / 朝侧 / 朝上）都要改，姿势和动作保持不变。

## 三、验收
1. 重画帧与同一动作其它帧并排，发型 / 刘海 / 服装颜色一致；
2. 小镇三方向与局内武者并排，手环 / 裤子 / 腰带 / 鞋子颜色一致；
3. 只改了列出的帧，其余帧像素不变。
