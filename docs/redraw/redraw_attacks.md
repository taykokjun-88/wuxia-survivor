# 重置画面计划书 补充：怪物 / Boss 的攻击动作（给 Gemini，与计划书 7、8、9 一起做）

> 背景：计划书 7~9 里每个怪物只有一条 4 帧循环动画，没有攻击动作。现在补上。
> 做法：**按「攻击类型」分组，同一类型用同一套动作设计**（同样的姿势节奏），每个怪物按自己的外观和武器画出来；这样 Gemini 只需要设计 6 种攻击模板，不用为 28 个怪物各想一套。

## 通用规格（同计划书 1 的通用规格）
- 文件放对应阶段的 `redraw_07 / 08 / 09`，**文件名 = `<怪物id>_attack.png`**（例：`bandit_attack.png`）。
- **小怪攻击动作：4 帧**，1 行横排；每帧格尺寸、人物高度、脚底位置**必须和该怪物的循环动画完全一致**（同一画布，脚底对齐），朝右。
- 不画地面阴影；纯 `#FF00FF` 背景。

## 一、小怪的 6 种攻击模板（每个模板 4 帧：蓄势 → 出手 → 最大伸展 → 收势）
| 模板 | 动作要点 | 用到的怪物（文件名） |
|---|---|---|
| **A 近战挥击** | 举起武器过肩 → 向前横劈 / 斜劈 → 武器伸到最远 → 收回 | `bandit`、`blade`、`soldier`、`kunlun`、`shaolin`、`th_yapu`、`elite` |
| **B 突刺** | 后退半步蓄力、武器后拉 → 向前猛刺 → 手臂伸直 → 收势 | `huashan`、`th_jiading` |
| **C 重踏 / 震地** | 单脚抬起、双手举过头 → 重重踏地 / 砸地 → 冲击姿势 → 站起 | `kongtong`、`th_jiguan` |
| **D 远程发射**（弓箭 / 投掷） | 拉弓或举手蓄力 → 放箭 / 掷出 → 手臂向前伸直 → 收势 | `archer`、`emei`、`th_yaotong` |
| **E 冲锋** | 低身蓄力、重心下沉 → 蹬地前扑 → 身体前倾腾空 → 落地 | `charger`、`th_dushe` |
| **F 受击**（可选，2 帧） | 身体后仰、表情痛苦 | 所有小怪，**先不画**，等 A~E 验收后再说 |
- 同一模板里不同怪物，**武器和服装各自不同**（山贼拿刀、弓手拿弓、峨眉拿剑 / 暗器、药童掷药瓶、毒蝎摆尾蜇刺）。
- 每个怪物的攻击**方向、幅度要和游戏里的实际攻击范围对得上**：近战范围约 1 个身位；突刺约 1.5 个身位；远程不需要碰到人，只要表现出「发射」动作。

## 二、Boss 与小 Boss 的动作（沿用上一版建议，等你确认后画）
| 对象 | 需要的动作 | 帧数 |
|---|---|---|
| **三关大 Boss**：`boss`（黑风铁锅王）、`s2_boss`（灭灶掌门）、`th_boss`（千机仙子） | `<id>_attack`（出招） | 6 |
| | `<id>_windup`（蓄力，Boss 出招前的预警动作，可循环） | 4 |
| | `<id>_hurt`（受击） | 2 |
| | `<id>_death`（死亡倒地，体积不缩水） | 6 |
| **9 个小 Boss**：`mini_boss_1~3`、`s2_mini_1~3`、`th_mini_1~3` | `<id>_attack` | 6 |
| | `<id>_death` | 4 |
- Boss 的招式很多（挥砍、跳跃、召唤、旋风、弹体……），**一个 `_attack` 动作先通用一套**（前挥击姿势），具体招式效果由已经做好的特效表现，不用每个招式单独画一套人物动作。

## 三、验收
- 每个怪物的攻击动作和它的循环动画并排放同一高度：**身高、脚底线一致**，只有动作姿势不同；
- 武器在「最大伸展」帧里不要出格；
