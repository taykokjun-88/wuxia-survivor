# 重置画面计划书 17（给 Gemini）：全部招式图标重画（37 个）

> 背景：现有招式图标和**招式名**对不上，也和**战斗里的特效**长得不一样（例如“斩蛟沉海刀”的图标是着火的剑，实际特效是青绿色巨浪；“沉渊重剑”图标是普通黑剑，等等）。
> 目标：每个图标一眼能看出**这一招叫什么、打出来是什么样**——图标的**主色、主体形状**和该招战斗特效一致。
> 参考：同目录 `ref17/skills_fist.png / skills_sword.png / skills_blade.png / skills_spear.png` 四张对照图：每格左上是**现在的旧图标**（要重画），右边是**战斗特效**（要照着它的颜色和形状来画），下面是名字和文件名。

## 一、规格
- **方形，1024×1024，透明背景 PNG**（我缩到 64×64 使用，所以主体要**大、简洁、轮廓清晰**，缩小后仍然看得清；不要小细节）；
- 统一的边框风格：**深色圆角方形底板**（深蓝黑 / 深紫黑，带细金属描边，和现有图标一样的底板尺寸），按门派区分描边色：武者 金、剑客 冰蓝、刀客 橙红、杨家将 银白；底板里放招式主体；
- 二次元精致画风，和现有 RO 风格的特效、角色同一系列；**图标里不要有文字、不要有数字**；
- 主体 = 该招式特效的**抽象简化版**（颜色一致、形状一致），再加一件能说明“是什么招”的物件（拳 / 掌 / 剑 / 刀 / 枪 / 棍）；
- 同一门派 9~10 个图标**风格一致，但彼此要能一眼区分**（不要都是“一把剑 + 光”）；
- 文件名 = 下表的 `id.png`，放 Drive 新建子文件夹 `redraw_17`；
- 先发 **每门派 2 个样图**（建议：斩蛟沉海刀、沉渊重剑、梅花枪法、回澜卸力诀）确认风格，再批量画。
