- 先发的设定图：四位主角各一张站姿（放大版），排在一起核对比例。

## 通用规格（十份计划书都适用，请先读）
**目标风格：RO（仙境传说）式精致 2D 精灵**
- 手绘感、柔和上色、细腻的明暗（至少 4 档色阶 + 高光），轮廓是**该部位的深色**（不是纯黑硬边），边缘平滑。**不要**复古 8-bit 的硬边抖动像素、不要大色块。
- 保持「一眼是同一个游戏」：同一阶段内所有图的光照方向、线条粗细、饱和度一致；**颜色和服装沿用现有设定**（见 `docs/art_spec13_v3.md` §1.2 / §1.3、`docs/art_spec19_proportions.md`），不换衣服。
- 角色统一二次元（成年、八头身为立绘；战斗精灵头身比约 1:5，和现有一致，腿不要短）。
**尺寸（比现在大约 2.3 倍）**
- 主角站直时「头顶到脚底」约 **120 px**（现在约 53 px）；每帧格 **256×256**，人物水平居中，**脚底固定在格内距底边 16 px**，朝右。
- 小怪 / Boss 按原高度 ×2.3；特效每帧分辨率 ≥ 原来的 2 倍（柔和半透明发光，不要硬边）。
**画布与背景**
- 纯 `#FF00FF` 单色背景（整张同一颜色，不要渐变 / 阴影 / 描边里混洋红）。
- 每个动作 **1 行横排**，帧等宽，同一角色所有动作**同一比例、同一画布、脚底对齐**。
**流程**
1. **先发 1 张设定图**（本阶段主角 / 敌人的站姿，放大版），我确认后再批量画；
2. 文件放 Drive 新建子文件夹 `redraw_NN`（NN 为阶段号），**文件名严格沿用本文表里的名字**；
3. 自查：同一角色所有动作并排放同一高度，身高、脚底线一致。
**我做的事**：重跑处理脚本、调整缩放 / 碰撞半径 / 显示大小、截图核对、跑完整测试，通过后再合并。
